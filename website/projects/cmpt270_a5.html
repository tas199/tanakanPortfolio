Console and GUI Application

Multiple-Choice Quiz System

Year 2024
Role Designer, Developer
Tools Java, Java Swing, Object-Oriented Programming (OOP), Unified Modeling Language (UML diagram)
Link GitHub ↗
Description

This project is a quiz application built in Java, where users answer one question at a time and can't move on until they've picked an answer. Once all the questions are done, the app automatically grades everything and shows the final score. It works with both a console (text-based) version and a GUI (graphical) version built using Java Swing, so users can interact with it either through typed commands or clickable buttons and windows. Behind the scenes, the project was built using solid object-oriented design principles, meaning the code is organized into reusable classes with clear responsibilities, structured into packages, and planned out ahead of time using a UML diagram before any code was written.
