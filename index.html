Hello, I'm Tanakan (Tan), a designer and developer based in Saskatoon, SK.

I have a Computer Science degree from the University of Saskatchewan, focused on UI design and full-stack web development, along with a degree in Electrical Engineering.

My experience includes building desktop applications with JavaFX, designing custom UI components and interactive graphics using MVC architecture, and developing full-stack web applications with React, Node.js, Express, Docker, and MySQL. I also work with Python, C, Go, Bash, and Java, with a foundation in object-oriented programming (OOP) and software development principles.
