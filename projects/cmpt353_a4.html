Full-Stack Posting System

Posting Web App

Year 2026
Role Designer, Developer
Tools Docker, Express, JavaScript, MySQL, Node.js, React, REST API
Link GitHub ↗
Description

This project is a small multi-page web app where users can create posts and view a list of them, similar to a simple blog or forum, built with a React frontend and a Node.js/Express backend. Users can navigate between a landing page, a page to view all posts, and a page to create a new one. All posts are saved in a MySQL database, so they don't disappear even if the app restarts. The whole system is packaged with Docker Compose, meaning the frontend, backend, and database all run together in containers with a single command.
