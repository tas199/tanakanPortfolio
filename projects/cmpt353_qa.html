Full-Stack Channel-Based System

Channel Q&A Platform

Year 2026
Role Designer, Developer
Tools Docker, MySQL, Next.js, App Router Architecture, Password Hashing, REST API, Session Authentication, TypeScript
Link GitHub ↗
Description

This project is a channel-based Q&A platform for programming questions (similar to Stack Overflow or Reddit website), where users can create channels, post questions, and reply in threaded discussions. Users can attach screenshots to their posts, vote on content with thumbs up/down, and search across questions, replies, and users. It includes full user accounts with secure login using hashed passwords (scrypt), plus an admin role that can moderate and remove content when needed. Behind the scenes, it's built with a Next.js frontend, a MySQL database to store everything, and Docker so the whole thing can run consistently with a single setup command.
